# simple-novel-page

陽春的靜態單一小說頁面

## 使用簡介

只需要注意三個東西

* 書名：`info.txt`
* 章列表：`chapters.txt`
* 節列表：`[章名]/list.txt`
* 節：`[章名]/[節名].txt`

選用的檔案

* 簡介：`about.txt`（沒有就顯示預設文字）
* 整本下載：`txtall.txt`（有這個檔案，簡介頁才會出現「下載TXT」按鈕）

### 列表格式

`chapters.txt` 和 `list.txt` 都是一行一筆，空行會被略過，行首尾的空白會被去掉，
所以章節名裡可以有空白。

### Markdown

節的檔名若是 `[節名].md`，實際檔案要存成 `[節名].md.txt`，內容會用 Markdown 算繪；
其餘的節一律當純文字，換行就是換行。

Markdown 由 `tools.js` 內建的簡易轉換器處理，不需外部函式庫，支援：

* 標題 `#`～`######`、段落、分隔線 `---`
* 粗體 `**粗**`、斜體 `*斜*`、行內程式碼、程式碼區塊（` ``` ` 或 `~~~`）
* 連結 `[文字](網址)`、圖片 `![說明](網址)`、引用 `>`
* 清單 `-` / `1.`（不支援巢狀）、行尾兩個空白強制換行
* `\*` 這類反斜線跳脫

不支援表格，原始 HTML 會被跳脫、原樣顯示成文字。

`.md` 是唯一會被當成副檔名的東西，所以節名裡可以有點，例如 `第1.5節` 會原樣顯示。

## 部署到 GitHub Pages

純靜態網站，不需要建置或 CI。

1. Fork 或把所有檔案放進自己的 repo
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`
3. 打開 `https://[帳號].github.io/[repo 名稱]/`

之後改內容只要 push，Pages 會自動重新部署。

根目錄的 `.nojekyll` 用來關掉 Jekyll 處理，避免 `_` 開頭的檔案被略過，請保留。
